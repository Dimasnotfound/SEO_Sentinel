
# SEO Sentinel

SEO Sentinel adalah alat crawler SEO yang dirancang untuk membantu Anda menganalisis dan memantau elemen-elemen SEO di sebuah website secara menyeluruh. Dengan tampilan terminal yang menarik dan informatif, SEO Sentinel menampilkan informasi penting seperti judul halaman, meta tags, heading, dan struktur internal link. Proyek ini sangat berguna bagi pengembang, pemilik website, dan konsultan SEO untuk mengoptimalkan performa website di mesin pencari.

## Fitur

- **Analisis Judul Halaman:** Mengambil dan menampilkan judul halaman website.
- **Ekstraksi Meta Tags:** Mengidentifikasi dan menampilkan semua meta tags yang ada di halaman.
- **Analisis Heading:** Menampilkan struktur heading (H1-H6) untuk memeriksa hierarki konten.
- **Deteksi Internal Links:** Menyaring dan menampilkan link internal yang terdapat di halaman.
- **Validasi URL:** Memastikan URL yang dimasukkan valid, dengan penambahan skema jika diperlukan.
- **Tampilan Terminal Menarik:** Menggunakan library [Rich](https://rich.readthedocs.io/) untuk output yang rapi dan mudah dibaca.

## Instalasi

Pastikan Anda sudah menginstall Python (minimal versi 3.6) dan paket-paket berikut:
- `requests`
- `beautifulsoup4`
- `rich`

Install paket-paket tersebut menggunakan pip:

```bash
pip install requests beautifulsoup4 rich
```

## Penggunaan

Jalankan program melalui terminal:

```bash
python seo_sentinel.py
```

Kemudian, masukkan URL website yang ingin Anda analisa saat diminta oleh program.
